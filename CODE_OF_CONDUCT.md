# Code of conduct

This is a small open-source project, and everyone taking part should be able to
do so without being treated badly.

## In short

Be kind and assume good faith. Welcome people whatever their background or level
of experience. Keep the conversation about the work, and keep it civil even when
you disagree.

Not welcome: harassment, insults, discrimination, posting other people's private
information, or persistent unwelcome behaviour. This holds in issues, pull
requests, commit messages and anywhere else connected to the project.

## If something goes wrong

If you see or experience behaviour that breaks this, report it privately to the
maintainer. On GitHub you can open a private security report (the **Security**
tab, **Report a vulnerability**), which reaches the maintainer and no one else;
use it for conduct reports too. Reports are taken seriously and kept
confidential.

The maintainer may remove comments, commits or contributions that break this
code, and may block anyone who keeps doing so.

This is based on the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
